Step 1

What is wrong today

I reviewed 250 emulator screenshots of the current build (light, dark and Arabic) and the design code, and scored them with the impeccable review rules for Apple and Android apps. The short verdict: the code underneath is tidy, but the look was invented from scratch, so it does not read as a native app.

AreaScoreMain finding
Platform conformance1 / 4Custom floating tab bar with no labels, pill buttons everywhere, hand-made glass and glow, card stacks where lists belong.
Visual hierarchy (critique)1 / 4Most screens are equal-weight cards. Three different styles are used for "the main button".
Appearance and theming3 / 4Good: almost every colour and size comes from one tokens file (37 stray colours, 6 stray font sizes). Dark mode still carries the glow.
Accessibility3 / 4Good: 48 dp touch targets and labels on controls. Tab icons have no visible text; some text is capped from scaling.
Performance, tabletsnot scoredNot measured in this pass. This redesign does not change either.

Severity: P1 is a real problem to fix before release, P2 is an annoyance, P3 is polish. I found no P0 (nothing blocks a task).

What already works, and stays

The workout screen's set table, hold to delete and rest timer. The exercise picker and filters. The exercise drawings and the body map. Correct right-to-left mirroring in Arabic. Honest empty states that never invent data. The tokens file, which lets most screens improve by changing one place.

Step 2

The new design rules

Fewer choices, used the same way everywhere. Orange is kept as the only accent and means "you can act here". Greys do the rest. Green, red and the three macro colours are for data and status only.

Spacing, corners, depth, motion

Spacing4, 8, 12, 16, 24, 32. Screen edge 16. Between sections 24.
Corners8 small controls, 12 cards and buttons, 16 sheets. Fully round only for chips.
DepthFlat. A card is a lighter surface on the page, with no shadow. Only sheets and the rest bar get a shadow or top line.
Motion120 ms for presses, 220 ms for screens and sheets, standard platform transitions. Honours "reduce motion".
Touch48 minimum for every control, 8 between neighbours.
RemovedAurora gradients, glass cards, the glowing orb, the capsule tab bar, title dots, dashed hint boxes.
