# Apple App Store — العربية

**الاسم:** ليفتريا: الطعام والتمارين

**العنوان الفرعي:** طعامك وتمارينك وتقدمك

**النص الترويجي:** يوميات الطعام وتمارين القوة واتجاهات الوزن والماء في تطبيق واحد. بياناتك على هاتفك. تقديرات هيكو اختيارية وتتطلب مفتاح Anthropic API خاصًا بك.

**الوصف:**

ابنِ عادات تناسب يومك.

ليفتريا يجمع يوميات الطعام وتمارين القوة ومتابعة التقدم في تجربة بسيطة تحفظ سجلاتك محليًا، دون الحاجة إلى حساب ليفتريا أو قاعدة بيانات سحابية.

سجّل طعامك بوضوح
سجّل الوجبات والكميات، ومنها أكلات مصرية مألوفة. تابع السعرات والعناصر الغذائية الكبرى والألياف والسكريات والصوديوم عندما تتوفر من المصادر. المعلومات الغذائية المفقودة تظل غير معروفة بدل عرضها كصفر. وتابع أكواب الماء بلمسة.

تمرّن بخطة
نظّم التمارين والقوالب، وسجّل المجموعات والتكرارات والأوزان والراحة، وارجع إلى سجل التدريب. استخدم اقتراحات الإحماء وأقراص الأوزان عند الحاجة.

شاهد تقدمك
تابع وزنك واتجاه تغيره بمرور الوقت. بعد توفر أيام كافية من تسجيل الطعام والوزن، يقدّر ليفتريا الإنفاق اليومي للطاقة وقد يقترح هدف سعرات أسبوعيًا جديدًا؛ ولا يغيّره دون موافقتك. ويمكنك مراجعة البيانات الصحية من مصادر الجهاز المتوافقة، عندما يتوفر الدعم وتمنح الإذن.

خصوصية تبدأ من جهازك
تبقى يوميات الطعام والتدريب والوزن والإعدادات على هاتفك. صدّر نسخة احتياطية أو ملفات CSV متى أردت. لا حاجة إلى حساب ليفتريا أو مزامنة سحابية تلقائية، ولا توجد إعلانات.

هيكو اختيارية
استخدم مفتاح Anthropic API الخاص بك لطلب تقدير وجبة من وصف نصي أو صورة (الصور ميزة تجريبية). يتطلب ذلك الإنترنت، ويعالج Anthropic المحتوى الذي تختار إرساله. راجع التقديرات وعدّلها قبل إضافتها إلى يومياتك.

ليفتريا مخصص للمتابعة الشخصية ولا يقدم نصائح طبية.
